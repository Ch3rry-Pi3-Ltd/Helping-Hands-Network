# Impact reporting template

Reviewed: 7 July 2026.

Purpose: give Healing Hands Network a simple, evidence-first way to collect
updates before publishing website impact summaries.

This is a template only. It should not be used to publish figures until the
charity has confirmed the source, meaning and approval owner.

## Minimum fields

| Field | What to record | Example format |
| --- | --- | --- |
| Reporting period | Date, month, quarter or trip period. | `April–June 2026` |
| Project area | Bosnia and Herzegovina, Ukraine, UK Veterans or another approved area. | `Ukraine Aid` |
| Activity summary | A short factual description of what happened. | `Delivered approved supplies to partner organisation` |
| People or partners supported | Who benefited, using safe, non-identifying wording unless consent exists. | `Partner clinic`, `veterans group`, `families supported by partner` |
| Quantity or evidence | Any number, count, document, receipt, photo, partner update or report. | `3 boxes`, `1 vehicle`, `partner email`, `receipt reference` |
| Source | Where the information came from. | `Volunteer report`, `partner confirmation`, `fundraising platform` |
| Consent status | Whether names, photos or quotes can be used publicly. | `No names/photos`, `photo approved`, `quote approved` |
| Safeguarding/privacy check | Whether the update risks identifying vulnerable people or sensitive locations. | `Checked`, `needs review`, `do not publish` |
| Charity approver | Person who approves the fact and wording. | `Susan`, `trustee`, `project lead` |
| Publication status | Current status for website use. | `Draft`, `approved`, `published`, `do not publish` |

## Website-ready update format

Use this once the minimum fields have been completed.

```text
Title:
Date:
Project:
One-sentence summary:
Main update:
Approved image:
Image caption:
Image alt text:
Call to action:
Approver:
```

## Rules for public impact summaries

- Prefer ranges or plain descriptions where exact figures are uncertain.
- Explain what a number means; do not leave readers to infer impact.
- Do not publish medical, therapy, trauma, safeguarding or location details
  that could identify or expose someone.
- Do not use names, quotes or faces without explicit permission.
- Keep the original evidence somewhere private and controlled; do not commit
  private evidence files to the public website repository.
- Record who approved the wording and when.

## First practical use

For the first review with Susan, collect one safe example update for each of:

1. Bosnia and Herzegovina.
2. Ukraine aid.
3. UK veterans.

Each example can stay private until the charity is comfortable with the
format.
