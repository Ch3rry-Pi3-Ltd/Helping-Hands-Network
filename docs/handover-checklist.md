# Pre-launch handover checklist

Use this checklist to establish ownership and operational readiness. Do not
record passwords, recovery codes, bank details or sensitive personal data in
this file.

## People and approval

- [ ] Charity owner for the website named.
- [ ] Content approver named.
- [ ] Safeguarding/privacy contact named.
- [ ] Fundraising-link and form owner named.
- [ ] Technical maintainer named.
- [ ] Emergency rollback decision-maker named.
- [ ] Expected response times and backup contacts agreed.

## Account ownership

- [ ] Healing Hands Network has appropriate access to the GitHub repository.
- [ ] Healing Hands Network has appropriate access to the Vercel project.
- [ ] Domain registration and renewal owner confirmed.
- [ ] DNS provider access and recovery method confirmed.
- [ ] Legacy WordPress/hosting access and backup owner confirmed.
- [ ] Fundraising-platform administrator access confirmed.
- [ ] Facebook administrator access confirmed.
- [ ] Multi-factor authentication enabled where available.
- [ ] Recovery methods belong to the organisation, not only one individual.

## Content and compliance

- [ ] Contact details and preferred enquiry routes approved.
- [ ] Programme descriptions, partners and dates approved.
- [ ] Donation destinations and offline forms approved.
- [ ] Volunteer requirements and application process approved.
- [ ] Testimonials and attributions approved.
- [ ] Image ownership, consent, safeguarding and alt text approved.
- [ ] Privacy notice approved and responsible contact confirmed.
- [ ] Any required charity, fundraising or lottery wording reviewed.
- [ ] Prototype notes and unapproved content removed.

## Technical readiness

- [ ] Final domain and canonical hostname agreed.
- [ ] `NEXT_PUBLIC_SITE_URL` set to the final HTTPS URL.
- [ ] Approved commit and production deployment recorded.
- [ ] GitHub Actions green.
- [ ] Full link, accessibility and production-build suite green.
- [ ] DNS zone and WordPress site backed up.
- [ ] Launch and rollback plan approved by the named operators.
- [ ] Monitoring and rollback window scheduled.

## Documentation handed over

- [ ] [Content maintenance guide](content-maintenance-guide.md) reviewed.
- [ ] [External-link audit](external-link-audit.md) reviewed.
- [ ] [Launch and rollback plan](launch-and-rollback-plan.md) reviewed.
- [ ] [Stakeholder confirmation pack](stakeholder-confirmations.md) completed.
- [ ] [QA report](qa-report.md) reviewed.
- [ ] Routine review dates entered into the charity's calendar.
