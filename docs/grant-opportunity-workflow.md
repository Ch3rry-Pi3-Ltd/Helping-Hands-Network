# Grant opportunity workflow

Reviewed: 7 July 2026.

Purpose: create a lightweight process for tracking potential grants without
overloading Susan or committing the charity to a new system.

This workflow should use approved charity facts only. It should not invent
impact figures, beneficiary stories or programme claims.

## Grant tracker fields

| Field | Purpose |
| --- | --- |
| Grant name | Identify the opportunity. |
| Funder | Organisation offering the grant. |
| URL | Source link. |
| Deadline | Submission deadline and time zone. |
| Amount | Grant size or range. |
| Eligible work | What the funder supports. |
| Fit | High, medium, low or reject. |
| Restrictions | Geography, charity size, project type, exclusions. |
| Evidence needed | Impact data, accounts, policies, quotes, partner letters. |
| Match funding needed? | Yes/no/unknown. |
| Owner | Person responsible for assessing or drafting. |
| Status | New, reviewing, drafting, submitted, won, rejected, not suitable. |
| Next action | Concrete next step. |
| Review date | When to check again. |

## Reusable charity information bank

Prepare approved boilerplate once, then reuse it.

- Charity name and registration number.
- Short mission statement.
- Longer charity overview.
- Programme summaries for Bosnia and Herzegovina, Ukraine and UK Veterans.
- Governance summary.
- Safeguarding/privacy statement.
- Financial year and latest accounts link.
- Approved impact summaries.
- Approved case studies or quotes.
- Standard contact details.
- Logo and approved images.

Keep this information reviewed and dated.

## Weekly workflow

1. Add new opportunities to the tracker.
2. Reject clearly unsuitable opportunities quickly.
3. Mark promising opportunities for review.
4. Check evidence and policy requirements before drafting.
5. Assign one owner for each active opportunity.
6. Reuse approved charity information.
7. Record the outcome.

## Scoring guide

| Score | Meaning |
| --- | --- |
| High | Strong fit, realistic deadline, evidence available, clear owner. |
| Medium | Possible fit but requires missing evidence or policy work. |
| Low | Weak fit or high admin burden. |
| Reject | Not eligible, poor fit or not worth the workload. |

## AI-assisted drafting boundary

AI may help structure a first draft only if:

- the source information is already approved;
- no private beneficiary, donor or volunteer information is pasted into the
  tool;
- a human checks every factual claim;
- Susan/trustees approve the final application.

AI must not invent impact evidence, quotes, financial details or delivery
claims.

## First practical step

Before tracking live grants, prepare the reusable charity information bank.
The current website prototype and impact-reporting template can supply the
structure, but Susan/trustees must approve the facts.
